# 一篇论文在系统里怎样流动

| 步骤 | 设计选择 | 对应代码 |
| --- | --- | --- |
| 发现 | 按期刊和日期翻页，以 DOI 等信息去重；将任务的进度写入 SQLite。 | [检索队列](../src/eduecon_radar/services/search_queue.py) |
| 补全 | 记录摘要来源，区分连接失败与来源未提供。缺失项可以稍后复查。 | [摘要补全](../src/eduecon_radar/services/abstract_enrichment.py) |
| 阅读 | 中文译文保留来源；题名判断与有摘要的判断区分展示。模型请求有批次预算。 | [处理流程](../src/eduecon_radar/services/local_pipeline.py) |
| 决定 | 论文资料全局共享。模型建议与人工决定分别按论文和研究方向保存。 | [方向存储](../src/eduecon_radar/services/profile_store.py) |
| 带走 | 用相同的筛选范围生成阅读清单、研究表格或 RIS。 | [论文库](../src/eduecon_radar/ui/views/paper_library.py) |

## 一个入口，两种数据生命周期

应用从同一个 Streamlit 入口装配数据库。Windows 启动脚本明确选择本地模式并绑定环回地址，使用个人库和可选密钥。默认部署从四条公开题录构建只读种子，为每个访客复制独立的临时库；人工审核、备注、书架、筛选和下载沿用个人工作台的代码。会话释放时回收临时目录。云端不启动联网队列，也不读取个人配置。摘要节选与编者阅读线索各自标注来源。[随库书目](../config/public_papers.json) · [工作区隔离](../src/eduecon_radar/ui/collection.py)

书目来源可逐篇核对。前三篇配有期刊摘要短节选与中译，贸易论文只展示题名和书目信息。[Duflo，2001](https://doi.org/10.1257/aer.91.4.795) · [Chetty 等，2011](https://doi.org/10.1093/qje/qjr041) · [Chetty 等，2014](https://doi.org/10.1257/aer.104.9.2633) · [Autor 等，2013](https://doi.org/10.1257/aer.103.6.2121)

## 实际验收

2026 年 11 月在隔离数据库与真实浏览器中完成以下检查。

- Windows 从干净环境安装后，在页面建库。六种教育经济学期刊的一周检索返回 11 条书目。保存判断、备注与书架后，下载的 CSV 包含相同的 DOI、决定和备注，重启后仍能接着读。另一次断网检索在恢复网络后，用原来的六刊和日期重查成功，没有触发模型调用。
- Ubuntu 24.04 和 Python 3.12 在独立虚拟机中从空环境安装，以普通用户启动服务。浏览器打开 Duflo 的论文，保存判断和备注，加入书架并下载 RIS，文件中的 DOI 与论文一致。首次加载曾有一个前端组件未能载入，刷新后恢复。
- 两个同时打开的访客工作区分别操作同一论文，判断、备注与书架彼此独立。测试中将工作区名额限制为一个，第二位访客看到等待提示，在释放名额后点「重试」即可进入。Streamlit Community Cloud 的公网访问与休眠唤醒仍待正式部署后验收。
- 统一入口接入原 Windows 个人库后，首页能找回既有方向和阅读进度。在独立访客会话打开 Duflo 的论文，保存决定、中文备注并加入书架，下载的研究版 CSV 包含同一 DOI 和备注。切至劳动经济学，该论文仍待判断。两次操作使用同一套审核组件。
- 在教育经济学下检索四篇论文，三篇从 OpenAlex 取得摘要，完成中文翻译和基于题名与摘要的初筛，共使用八次真实 DeepSeek 请求。
- 保存与模型建议不同的人工决定及备注，收藏、下载 RIS、关闭并重启，再读回相同的判断。切换到劳动经济学能找到相同书目，人工判断独立。
- 对缺少摘要的论文在副本中提前触发次日复查，公开来源仍未返回摘要。该测试验证重启恢复路径，未做连续数月的运行压力测试。
- 四本劳动期刊的一周检索得到 42 条不同记录。以同一 DOI 重复检索已分析论文，保留既有结论。逐字段核对研究版 CSV、Markdown 长摘要及 RIS 书目信息。

接口覆盖随来源、年份和访问条件变化。题名或摘要支持的是阅读前的初筛；全文论证、识别假设与外部有效性仍需研究者核查。
